Cello — Revolutionizing Communication Anxiety

Mijn Rol: Chief Technical Officer (Stage & Co-founder)

Cello is een baanbrekende, bekroonde mobiele applicatie die jongeren empowert om hun telefoonangst te overwinnen via next-gen gamificatie. Als enige tech-architect in een dynamisch team van vier studenten heb ik het volledige ecosysteem vanaf nul opgebouwd en succesvol gelanceerd in de Google Play Store.

Play Store 📱 Website 🌐 Socials 🔗

⚙️ Cutting-Edge Tech Stack

Geoptimaliseerd voor maximale performantie op lokale server-infrastructuur:

• Frontend: React Native met TypeScript voor cross-platform synergie en dynamische i18n.
• Backend: Java Spring Boot REST API gekoppeld aan een robuuste PostgreSQL database.
• AI & Spraak: Python-laag met lokaal Whisper-model voor real-time Speech-to-Text en Deepgram failover.
• Local LLM: Ollama hosting (IBM Granite 4.1 en Google Gemma 4) voor diepgaande post-conversatieanalyses.
